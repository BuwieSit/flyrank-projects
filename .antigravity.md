# 🤖 Antigravity CLI Rules & Project Conventions

This file guides the `agy` agent on the specific standards, commands, and patterns used in the Coffee Shop Showcase project.

---

## 📋 System & Execution Commands
* **Install dependencies:** `npm install`
* **Local Dev Server:** `npm run dev`
* **Production Build:** `npm run build`

## 💻 Stack & Architecture Guidelines
* **Tech Stack:** React (Vite) + Tailwind CSS + Node.js (LTS).
* **Component Structure:** Keep UI components modular and reusable (e.g., `src/components/ProductCard.jsx`, `src/components/MenuGrid.jsx`).
* **Styling:** Use utility-first classes via **Tailwind CSS**. Do not write custom vanilla CSS files or inline styles unless completely necessary.
* **State Management:** Prioritize React's local state (`useState`) for menu filtering, search inputs, and price toggles.
* **File Naming Conventions:**
  * Component files: PascalCase (e.g., `Navbar.jsx`)
  * Utilities/Data files: camelCase (e.g., `menuData.js`)

## 🌿 Git & Workflow Rules
* Always write commit messages adhering strictly to **Conventional Commits 1.0.0** (e.g., `feat(ui):`, `fix(price):`, `chore(deps):`, `docs(readme):`).
* If editing multiple files, ensure the build passes before completing the turn.

## 💡 Learned AI Workflow Rules
* **Explicit Directory Sandboxing:** Always declare the exact target folder boundary (e.g., `dev-cafe/`) at the beginning of a prompt to prevent the agent from scattering files in parent directories.
* **Define Abstract UX Terms:** Never use ambiguous phrases like "fix UI/UX" or "less clutter." Instead, specify exact layout components (e.g., "Implement a Tailwind grid layout, restrict card details to 4 items, and add a filter bar").
* **Automated Import Verification:** Include a compilation or build verification command (`npm run build`) within the prompt loop to force the agent to fix breaking path/import errors before ending the turn.
