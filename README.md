# ☕ Dev Cafe Showcase

A responsive web application designed to showcase a coffee shop's menu, product details, dynamic pricing, and venue amenities. Built as part of an internship capstone project focusing on AI-assisted development workflows.

---

## 🌟 Cafe Amenities & Features

Dev Cafe is built specifically with developers, tech enthusiasts, and productivity seekers in mind, while remaining warm and welcoming to all coffee lovers.

* 📡 **High-Speed Wi-Fi:** Fast, reliable internet throughout the space for seamless remote work and coding.
* 🔌 **Developer-Friendly Power Outlets:** Accessible power sockets at every station—optimized for multi-device developer setups, open to all customers.
* 🚪 **Private Meeting Rooms:** Dedicated spaces available for team standups, group projects, and collaborative sessions.
* 📚 **IT & Tech Library:** A curated collection of books covering software development, AI, data science, cybersecurity, and design.
* 🎲 **Board & Physical Games:** A variety of tabletop games to unwind, take breaks, and bond with fellow patrons.

---

## 🛠️ Tech Stack
* **Frontend:** React (Vite)
* **Styling:** Tailwind CSS
* **Tooling:** Node.js (LTS), Git

## 🚀 Getting Started

### Prerequisites
Ensure you have [Node.js (LTS)](https://nodejs.org/) installed on your machine.

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd dev-cafe
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the URL shown in your terminal).
