# ☕ Dev Cafe Showcase

A responsive web application designed to showcase a coffee shop's menu, product details, and dynamic pricing. Built as part of an internship capstone project focusing on AI-assisted development workflows.

---

## Tech Stack
* **Frontend:** React (Vite)
* **Styling:** Tailwind CSS
* **Tooling:** Node.js (LTS), Git
